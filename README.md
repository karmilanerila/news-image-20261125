A newspaper front page that sums up the world's news of Wednesday
25 November 2026 in one image, drawn entirely in code with the Python
standard library (no Pillow, no network).

- Lead story: mines in the Strait of Hormuz — two tankers hit, oil and
  shipping on edge.
- AI sell-off: NVIDIA -7%, Nikkei -2.76%, AI boom doubts.
- Space: Pakistan's first astronaut reaches China's space station.
- Cartagena: all hostages freed after a supermarket siege.
- Ticker: Australia–Solomon Islands treaty, Ukraine hits a Russian
  warship off Libya, COP31 collapses, Huawei convicted, Bangladesh
  wage +36%.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Writes `out/entry.png` (1024x1024 PNG, deterministic — two runs write
identical bytes).
